# infraestructura-red-empresarial
Diseño y Desarrollo de una Infraestructura de Red Empresarial Segura con Servicios Virtualizados y Almacenamiento Centralizado en la Nube para una Empresa de Seguridad

## Tecnologías utilizadas
- Cisco Packet Tracer
- VLAN y ACL
- Windows Server 2022
- Active Directory
- DNS y GPO
- Ubuntu Server
- Nextcloud
- LDAP
- Amazon Web Services
- EC2 y VPC

## Arquitectura del proyecto
El proyecto integra una red empresarial segmentada mediante VLAN con servicios virtualizados en AWS. Windows Server administra los usuarios, grupos y políticas de seguridad, mientras que Ubuntu Server aloja Nextcloud para el almacenamiento centralizado.
